# 0001 · Phase 1 foundation choices

Status: proposed with the Phase 1 PR, for founders' review.
Date: 8 November 2026

Small technical choices made while building the foundation. None changes the approved product scope or architecture.

| Choice                                                                                            | Why                                                                                                                                                                                                                                                    | Reversible?                |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------- |
| **TypeScript 6.0.x**, not 7.0                                                                     | Expo SDK 58 ships and supports TypeScript 6.0; typescript-eslint supports up to 6.0. Anticipated in the technical plan (risk 11).                                                                                                                      | Yes, when Expo supports 7. |
| **ESLint 9**, not 10                                                                              | `eslint-plugin-import` (used by Expo's config) does not support ESLint 10 yet.                                                                                                                                                                         | Yes.                       |
| **pnpm isolated installs** (no hoisting)                                                          | Works with Expo SDK 58: iOS, Android and web bundles build. Jest needed two small mappings, documented in `apps/mobile/jest.config.js`.                                                                                                                | Yes.                       |
| **Reanimated removed until Phase 6**                                                              | Phase 1 only needs two small animations (tab pill, skeleton). They use React Native's built-in `LayoutAnimation` / `Animated`, which respect Reduce Motion. Reanimated 4's Jest setup needs extra work; it returns with the rain animation in Phase 6. | Yes.                       |
| **Expo Router typed routes off**                                                                  | Typed routes need generated files that only exist after `expo start`, which would make CI typechecks fragile. Revisit once CI runs Expo's type generation.                                                                                             | Yes.                       |
| **Fonts self-hosted on the web portal** (`@fontsource-variable`)                                  | No request to Google Fonts at build time or from visitors' browsers (privacy and reliability).                                                                                                                                                         | Yes.                       |
| **Both candidate typefaces bundled** (Manrope, Onest)                                             | Founders compare them in the Design preview screen (P-14). The one not chosen is removed afterwards.                                                                                                                                                   | Yes.                       |
| **Lucide icons** (`lucide-react-native`)                                                          | Clean line icons close to the visual reference, tree-shakable, consistent stroke weights.                                                                                                                                                              | Yes.                       |
| **Environment marker in the database** (`private.runtime_settings`), failing closed to production | Lets the placeholder guard (P-11) work without trusting the client. A database that was never configured behaves as production.                                                                                                                        | n/a                        |
| **Admin language via cookie + Accept-Language**, switched with a server action                    | Works without client JavaScript; cookie is httpOnly, SameSite=Lax.                                                                                                                                                                                     | Yes.                       |
